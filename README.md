## Republish for a live re-review

Any of these redeploys GitHub Pages:

1. **Push to `main`** — the workflow runs automatically.
2. **Manual run** — GitHub → **Actions** → **Deploy to GitHub Pages** → **Run workflow**.

```bash
gh workflow run deploy-pages.yml
```
